## 1. 总体技术架构

```text
浏览器（Chrome / Edge / Firefox）
   │  HTTP / JSON（Axios，携带 JWT）
   ▼
前端 Vue3 SPA ──────────────── 后端 Spring Boot 3.2.x
├─ 用户端（/home ...）          ├─ interceptor  JWT 鉴权拦截器
├─ 管理端（/admin ...）         ├─ controller   接口层（统一返回 Result）
├─ router  路由权限守卫         ├─ service      业务层（核心规则）
├─ stores  Pinia 状态           ├─ mapper       MyBatis-Plus 数据层
└─ utils   Axios 拦截器         ├─ config       跨域/MyBatisPlus/Web 配置
                                ├─ schedule     定时任务（爽约/解禁/完成）
                                └─ handler      全局异常处理
                                          │
                                          ▼
                                  MySQL 8.0（library_booking 库）
```

**端口约定**：前端 5173（Vite Dev Server，代理 `/api` → 8080）；后端 8080；MySQL 3306。

**运行环境**：JDK 17+（Spring Boot 3.x 强制）、Maven 3.6+、Node.js 18+、MySQL 8.0。

### 2.3 核心类设计

#### 2.3.1 统一返回封装 Result

```java
@Data
public class Result<T> {
    private Integer code;   // 200成功 401未登录 403无权限 500系统异常 业务码 1xxx
    private String msg;
    private T data;
    public static <T> Result<T> success(T data);
    public static <T> Result<T> error(Integer code, String msg);
}
```

#### 2.3.2 全局异常处理

```text
GlobalExceptionHandler (@RestControllerAdvice)
├─ BusinessException            → Result.error(业务码, msg)
├─ AuthException                → 401 / 403
├─ MethodArgumentNotValidException → 提取首条校验信息返回（参数校验）
├─ DuplicateKeyException        → 友好提示（学号重复等唯一键冲突）
└─ Exception                    → 500 "系统繁忙，请稍后再试"（记日志）
```

#### 2.3.3 JWT 鉴权拦截器

```text
JwtInterceptor.preHandle:
1. 放行白名单：/api/auth/**、/api/notice/list、静态资源、knife4j 文档
2. 取 Header: Authorization: Bearer <token>
3. 校验失败 → 401 "未登录或登录已过期"
4. 解析成功 → UserContext 存 {userId, roleKey}，afterCompletion 清理 ThreadLocal
5. @RequireRole("super_admin") 注解方法二次校验角色，不符 → 403
```

#### 2.3.4 核心业务实现（BookingServiceImpl / CreditServiceImpl）

```text
createBooking(dto)  —— @Transactional
 1. 用户禁用校验（is_disabled=1 → 返回禁用原因+解禁时间）
 2. 规则校验：开放时间内 / 30min粒度对齐 / 30min≤时长≤4h / 开始时间>now / 日期≤今+advance
 3. 每日单数校验：count(user_id, booking_date, status≠3) < max_per_day
 4. 座位冲突校验：SELECT ... FOR UPDATE 区间相交（seat 维度）
 5. 用户时段冲突校验：区间相交（user 维度）
 6. 写入订单 status=0 → Result.success

cancel(orderId)     —— 仅本人，now < start_time，status 0→3
checkin(orderId)    —— 仅本人，now ∈ [start, start+late_min]，status 0→1
checkout(orderId)   —— 仅本人，status=1，status→2，记录 checkout_time
renew(orderId, newEnd) —— status=1，校验延长段无冲突、总时长≤max，更新 end_time

定时任务 BookingSchedule（每分钟）：
 scanNoShow()   —— 待签到且 now > start+late → 爽约（事务内：订单置4 + creditService.deduct）
 scanAutoFinish() —— 进行中且 now > end → 自动签退置2
 scanLiftDisable() —— 到期禁用 → 解禁恢复60分

CreditServiceImpl（@Transactional，核心）：
 deduct(userId, score, type, orderId, operator)
   1. UPDATE sys_user SET credit_score = credit_score - #{score}
   2. 插 violation_record
   3. 若 credit_score < threshold 且当前无生效禁用：
      is_disabled=1, disable_end_time=now+disable_days，插 disable_record
   4. 发站内信
 lift(userId, operator)   —— 解禁：is_disabled=0，记录置 is_lifted=1，credit 恢复至 60
 adjust(userId, score, reason) —— 超管调分，减分后触发禁用判定
```

### 3.2 前端强制规范实现

**① Axios 拦截器（api/request.js）**

```text
请求拦截：自动携带 Authorization: Bearer {token}
响应拦截：
  code=200   → 返回 data
  code=401   → 清除 token，跳转 /login（管理端 /admin/login）
  code=403   → ElMessage "无权限操作"
  其他       → ElMessage 提示 msg，reject
网络异常     → 统一 "网络异常，请稍后再试"
```

**② 路由权限控制（router/guard.js）**

```text
beforeEach:
1. meta.requireAuth 且无 token → 重定向登录页（记录 redirect）
2. meta.role 存在且与当前用户角色不符 → 403 提示，回首页
3. 管理端路由统一校验 role ∈ {librarian, super_admin}
   超管专属路由 meta.role = 'super_admin'（用户/角色/禁用/设置/日志）
4. 登录后按角色分流：学生 → /home，管理员 → /admin/dashboard
```

**③ Pinia 状态统一管理（stores/user.js）**：token、userInfo、roleKey、登录/登出 action、未读消息数；stores/app.js 缓存楼层列表与系统配置，避免重复请求。

**④ 界面规范落地（styles/variables.css）**：以 CSS 变量定义 9 个规范色值、`--radius: 12px`、`--shadow: 0 4px 16px rgba(74,144,226,.12)`，并在 global.css 覆盖 ElementPlus 变量（`--el-border-radius-base: 12px`、主色 `#4A90E2`）。

## 4. 接口规范

- 统一前缀 `/api`；管理端 `/api/admin/**`；
- 请求：GET 查询 / POST 新增与业务操作 / PUT 修改 / DELETE 删除；
- 返回统一 `Result<T>`；分页返回 `PageResult<T>`；
- 时间格式：`yyyy-MM-dd HH:mm:ss`（Jackson 全局配置）。

代表性接口：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/auth/login | 登录（学号+密码）→ LoginVO |
| POST | /api/booking | 提交预约（BookingCreateDTO） |
| PUT | /api/booking/{id}/checkin | 签到 |
| PUT | /api/booking/{id}/checkout | 签退 |
| PUT | /api/booking/{id}/renew | 续时 |
| PUT | /api/booking/{id}/cancel | 取消 |
| GET | /api/room/{id}/seat-map?date= | 座位平面图（含当日状态） |
| GET | /api/user/credit | 我的信用面板 |
| PUT | /api/admin/disable/{userId}/lift | 超管手动解禁 |
| GET | /api/admin/stat/utilization?dim=day | 利用率统计 |
| GET | /api/admin/stat/export | 导出 Excel |
