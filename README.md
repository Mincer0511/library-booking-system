广西职业师范学院图书馆自习室预约系统

> 基于 Vue3 + Spring Boot 的前后端分离校园自习室预约管理系统 · 本科毕业设计项目

本项目针对高校图书馆占座乱象、座位资源分配不均、管理效率低下的痛点，实现了座位在线预约、签到签退、信用分约束、运营数据统计的全流程数字化管理。采用蓝白色调卡通校园风格界面，支持三级角色权限，具备完整的业务闭环与并发控制机制。

---
✨ 项目概述
- **覆盖范围**：图书馆 1-5 层全部自习室，完整的座位布局可视化
- **角色体系**：学生用户 / 图书馆管理员 / 超级管理员 三级角色，权限严格隔离
- **业务闭环**：预约 → 签到 → 使用 → 签退 → 超时爽约 → 信用分扣减 → 禁用 → 自动解禁
- **并发控制**：数据库行锁机制保障高峰时段预约不超卖，数据一致性强
- **自动运营**：定时任务实现状态自动流转、到期提醒、自动解禁，无需人工干预

🎯 核心特性

 学生端
- 🏠 自习室按楼层浏览，实时展示空余座位数，支持按类型筛选
- 🪑 可视化座位平面图，不同颜色区分座位状态，悬浮查看详情
- 📅 选择时间段预约，自动校验时间冲突、预约次数、禁用状态
- ✅ 手动签到 / 签退 / 续时，灵活管理使用时长
- 💯 信用分仪表盘，违规记录、禁用状态与解禁时间一目了然
- 🔔 站内消息中心，接收预约提醒、违规通知、系统公告
- ⭐ 收藏常用自习室，快速跳转预约
- 👤 个人信息管理，密码修改、头像更换

 管理端
- 📊 数据看板，核心运营指标 + 座位利用率趋势图、热门时段分布图
- 🏫 自习室与座位管理，支持批量生成座位、单个编辑状态
- 📋 全量预约订单管理，多条件筛选、强制取消、备注添加
- ⚠️ 违规记录管理，手动添加/撤销违规，同步更新信用分
- 🚫 禁用用户管理，支持手动提前解禁
- 👥 用户账号管理，角色分配、密码重置
- 📢 系统公告发布、置顶、编辑
- ⚙️ 全局系统参数配置
- 📝 操作日志全记录，关键行为可追溯
- 📥 运营数据支持 Excel 导出

 🚀 本地启动
 环境要求
- JDK 17+
- Node.js 16+
- MySQL 8.0+
- Maven 3.9+

1. 数据库准备
1.  新建 MySQL 数据库 `library_booking`，字符集 `utf8mb4`
2.  后端首次启动会自动创建数据表并初始化基础数据

2. 后端启动
powershell
进入后端目录
cd library-server

修改配置文件
编辑 src/main/resources/application.yml，修改数据库密码为本地密码

打包启动
mvn clean package -DskipTests
java -jar target/library-server-1.0.0.jar

后端服务默认端口：`8080`

 3. 前端启动
powershell
进入前端目录
cd library-web

安装依赖
npm install

启动开发服务
npm run dev

前端服务默认地址：`http://localhost:5173`
